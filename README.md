# Birleşik Dergi Yazıları

Birleşik Dergi yazılarının barındırıldığı depo

# Depo Yapısı

- `core/`: Dergimizin güncel yazıları ve yayım politikası
- `authors/`: Yazar katkıları (`aile/` altında aile ve bilişim yazıları)
- `old/`: Eski blog yazıları
- `img/`: Yazılarda kullanılan görseller

# Değişiklik Özeti

Depo, Ağustos 2024'te WordPress yazılarının toplu aktarımıyla başladı. Ardından logo, haber ve rehber yazıları (Firefox, OpenStreetMap, hacker how-to, Milis Linux) eklendi. 2025'te yayın politikası, "Özgürlük mü, Güç mü?" çevirisi ve topluluk katkıları (Muha Aliss, Malik Dündar) geldi; Linux açılış/önyükleme ve arama algoritmaları yazıları yayımlandı. Şubat 2026'da eski yazılar `old/`, güncel yazılar `core/` dizinine taşındı; ardından "Özgür Yaşam", "Açık mı Kaynak?", "Özgür Yazılım ve Kapsayıcılık" ve aile/bilişim yazıları eklendi. Ayrıntılar için [ChangeLog](ChangeLog) dosyasına bakınız.
